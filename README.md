# Hey, I'm @ssolidssnake9

I build local-first software with an AI pair-programmer: voice interfaces,
automation agents, scrapers, and ML from scratch. Free tiers and open weights
only — nothing phones home unless it has to.

## What I do

- **Local voice interfaces** — speech-to-text → LLM → text-to-speech pipelines
  that run 100% offline on consumer hardware
- **Automation agents** — scheduled watchers, streak trackers, milestone
  notifiers that run quietly and report at milestones
- **Web scraping & data** — scrapers, trend analyzers, interactive dashboards
  that turn raw datasets into readable insights
- **ML from scratch** — NumPy classifiers, evaluation metrics, honest
  comparisons against sklearn baselines
- **Design systems** — original visual languages with enforced contrast rules
  and a linter that fails the build on off-system colors
